# Portfólio — Desenvolvedor

Portfólio pessoal desenvolvido para apresentar minhas habilidades, projetos e conhecimentos em desenvolvimento de software.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Projetos em destaque

- **Minha Loja:** projeto de e-commerce.
- **FlashCard.IA:** aplicação de inteligência artificial para criação de flashcards.
- **Ajuda.ai:** plataforma voltada à conexão entre pessoas e iniciativas de ajuda.
- **Capital em Foco:** landing page para venda de cursos.

## Funcionalidades

- Layout responsivo.
- Animações e microinterações.
- Seções de habilidades, projetos e apresentação profissional.
- Links para projetos e repositórios.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
